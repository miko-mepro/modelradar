冻结参考与标准化

radar-data.js 提供实测数据，radar-reference.js 提供冻结的参考模型、配置、数据版本、参考时间及逐项成绩。参考成绩顺序与参考模型列表一致，缺项为 null，0 分属于有效实测。搜索、筛选、勾选和增删展示模型均不改变参考基准。

每项至少需要 5 条有效参考。均值为 μ_j = Σx / n，总体标准差为 σ_j = √(Σ(x − μ_j)² / n)，标准分为 z_mj = (x_mj − μ_j) / σ_j。参考不足或标准差为零时明确移出计分，其余有效项目统一归一权重。参考样本只有十来个模型，尺度估计本身存在误差，模型间一至三分的差距不足以单独断定强弱。

用途与固定的两层权重

维度与评测均使用优先级：0 不纳入、1 一般、2 重要、3 核心。默认用途侧重编码、推理、长文与工具工作流，可调整并恢复默认。维度权重为 W_d = p_d / Σp，维度内分项权重为 v_dj = q_j / Σq_同维度，分项占总分权重为 w_j = W_d × v_dj。分项求和只包含可标准化的项目。

同一套权重适用于所有模型，模型缺项不重新分配权重。至少一个维度须有正优先级，每个纳入综合排名的维度须至少有一项参考有效、正优先级的评测；否则明确提示，评分显示“—”。维度优先级为 0 时仍可查看其维度指数，但不进入综合分；维度内有效分项全部为 0 时，该维度显示“—”。

同维度近邻与回归估计

缺项只使用同一维度内、已纳入且有真实实测的其他评测作为比较项。候选参考模型必须同时具备目标项和全部比较项实测，候选至少 5 个；同一模型不能作为自己的邻居。按比较项标准分差的均方根距离选择最近 3 个，距离相同按冻结参考顺序排列。

目标成绩的邻居中位数为锚点 y₀，各比较项的邻居中位数为 a_j。邻居特征为 D_ij = (x_ij − a_j) / σ_j，目标差为 t_i = (y_i − y₀) / σ_目标。固定收缩系数 λ = 1，局部回归系数为 β = (DᵀD + λI)⁻¹Dᵀt，候选估计为 ŷ = y₀ + σ_目标 × Σ[β_j × (x_待估,j − a_j) / σ_j]。各项尺度取自参考标准差，收缩用于限制小样本下的校正幅度。

比较项只使用真实实测，不跨维度外推；优先级为 0 的评测不作为比较项。参考 近邻插补与 岭回归原理。候选估计单独保存，不写回原始 breakdown；明细展示锚点、各比较项校正量以及是否采用。

遮挡验证与启用条件

每个“目标项＋比较项组合”单独进行留一遮挡验证。每次完整移除被验证模型，用其余参考重新计算均值和标准差、寻找邻居、拟合局部回归，并与其余参考的目标项均值预测比较。验证与实际补分共用同一套锚点和校正公式。只有可以完整预测的案例进入两种方法共同的验证集合，越界预测照常计入验证误差。

至少 5 个有效验证案例，且校正估计的平均绝对误差 MAE = mean(|预测 − 实测|) 严格小于均值基线 MAE，才启用该规则。验证未通过、候选不足、没有相关实测或候选估计超出 0–100 时，标记“证据不足”，按 z = 0 参与，明细说明原因。验证通过仅说明该参考样本上的误差更低，不保证未知成绩准确；无相关证据时，中性值是必须排名时的约定。

维度、综合指数与证据构成

实测项使用实测标准分；估计项使用经验证的近邻估计标准分；证据不足项使用 0。维度标准分为 Z_md = Σ(v_dj × z_mj)，综合标准分为 Z_m = Σ(W_d × Z_md)；二者分别通过 S = 100 / (1 + exp(−Z)) 映射为指数。50 表示参考平均水平，不代表正确率或胜率。综合分合成维度标准分，不平均已映射的指数。

每个分项按状态归入实测、估计或证据不足，三类分别累加固定权重，合计 100%。维度展示维度内占比，综合展示占总分比例；三类占比不乘入能力分，估计不计入实测覆盖。“仅有效实测覆盖 100%”按当前综合权重筛选。总览与维度均按对应完整标准分降序，同分时按 AA 智力指数、数据顺序排列。

展示与数据接口约束

表格维度列和总览雷达共用维度指数；分项图只展示原始实测。相对图以全部展示模型中的该维最高指数或该项最高实测为 100，只缩放图形。原始缺项显示“—”，近邻估计独立列出，明细提供参考均值、标准差、权重、贡献、邻居、中位锚点、回归校正量和验证误差。

模型需提供 id、name、detail、creator、color、url、breakdown 和 intelligenceIndex。维度 items 提供 key、label、metric、source；维度与各项均提供整数 defaultPriority（0–3）。breakdown 仅记录 0–100 的实测，未知维度或键直接报错。人类偏好 Elo 预先按冻结参照换算为 100 / (1 + 10^(-(elo − eloRef) / 400))。

增加展示模型只需写入展示数据；增加评测须提供匹配的参考记录，尚无参考时显式记录 null，该项不计分。新增维度若没有可用评测，默认维度优先级须为 0。评测名称、来源或计分口径与冻结参考不一致时直接报错，须提供匹配参考版本。
